# Security Policy

## Supported Versions

This project is deployed continuously from the `main` branch rather than
released in discrete versions — only the latest commit on `main` is
supported for security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
GitHub issue. Instead, report it privately by emailing
**fudail.zafar@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (proof-of-concept code or requests, if applicable)
- Any suggested mitigation, if you have one

You should expect an initial response within a few days. Once the issue is
confirmed, we'll work on a fix and coordinate disclosure timing with you
before any public write-up.

## Scope

This policy covers the application code in this repository. It does not
cover third-party services this project integrates with (Supabase, AWS S3,
Google OAuth, Vercel, Upstash) — please report vulnerabilities in those
services directly to their respective vendors.
